# Conversion validation: SDPA (.dat-s) to the cuADMM TXT format

Converter `scripts/sdpa_to_cuadmm.py`, independent checker `scripts/check_conversion.py` (a separate SDPA reader, it does not import the converter), driver `scripts/convert_all.sh`, logs in `logs/conversion/`. Generated by `scripts/conversion_summary.py`; the numbers are in `data/conversion_checks.csv`.

## Mapping

SDPA primal (Mittelmann/SDPA convention): max tr(F0 Y) s.t. tr(F_i Y) = c_i, Y psd; dual min c^T x s.t. sum_i x_i F_i - F0 = X psd. cuADMM solves min <C, X> s.t. A(X) = b, X in K. The converter sets C = -F0, A_i = F_i, b = c, so that X_cuADMM = Y_SDPA, y_cuADMM = -x_SDPA, S_cuADMM = X_SDPA, and the SDPA objective is -<C, X>. Negative SDPA block sizes (diagonal blocks) become `l` blocks; a 1 x 1 PSD block is stored as `l 1` (the same cone) and recorded as `s` in `dimacs_blocks.txt`, which the DIMACS norms use. Matrices are stored as svec (upper triangle, column major, index j(j+1)/2 + i, off-diagonal entries times sqrt 2).

The orientation and sign are confirmed independently: Clarabel (interior point, not MOSEK) solves the converted data, and -<C, X*> equals the published objective (after the scale factors of `accuracy_protocol.md` section 4); see `data/clarabel_reference.csv`.

## Checks

1. structure: block sizes and kinds against the SDPA header, vec_len, con_num, largest indices; b equals the SDPA c vector;
2. forward: for 3 random block-diagonal symmetric Y, <F_k, Y> from the full symmetric definition equals (A svec(Y))_k, and <F_0, Y> = -C . svec(Y);
3. adjoint: for 3 random w, the upper triangle of sum_k w_k F_k - F_0 equals svec^-1(A^T w + C);
4. round trip: the TXT data written back to SDPA and re-read reproduce every original entry;
5. rank: A A^T is positive definite (dense eigenvalues) when m <= 6000; for mater-5 and mater-6 (m = 10,143 and 20,463) the rank comes from the CHOLMOD factorization report of cuADMM (no tiny or non-positive pivots; recorded in every run summary as aat_tiny_pivots and aat_nonpositive_pivots);
6. input hygiene: no explicit duplicates, no non-finite values; explicit zeros dropped and lower-triangle entries mirrored are counted.
